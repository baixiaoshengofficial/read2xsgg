先在宿主机同一用户下完成 CLI 登录，再运行 npm run agent:bridge。容器只通过私有 Unix Socket 调用，不挂载登录凭据；保存后点击“测试当前 AI 接入”。

API Key 存于 Docker 的 /data/private-settings/ai.json，浏览器接口不会回显。HTTP 本地模式不读取宿主机 Agent 的登录文件；CLI 模式由宿主机桥接进程使用已登录的客户端。网页证据会限制大小并脱敏；MCP 仅开放筛选后的只读浏览工具。
